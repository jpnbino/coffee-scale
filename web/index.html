    Before you order

      These checks compare the design, the placement file and each pad's paste opening. They don't replace DRC, the assembler's preview or a datasheet check.

      Pin maps to compare with datasheets ·

      Every part whose symbol names its pins. A footprint whose pad numbering does not match the real part (SOT-23 transistors, diodes, regulators) is a classic cause of a board spin: check each row against the manufacturer's datasheet.

      Reading the released files…

      Drawn from the actual Gerber and Excellon files; the paste layers come from the current build's stencil files. Mask layers show openings. All layers share one absolute coordinate frame; none is fitted on its own. This is a review aid, not fabrication sign-off.
